Project Overview

Sentinel Finance is an autonomous AI research agent that fuses live market data with private analyst reports. Unlike a naive chatbot, it stands guard at every boundary: it blocks prompt-injection attempts at the input, and it softens over-confident advice or blocks proprietary leakage at the output. The guiding principle is speed without recklessness: the agent researches quickly, while a safety layer keeps its answers responsible.

The Problem

Investment research is slow and manual. An autonomous agent can compress hours into minutes, but one that can be jailbroken, leaks confidential reports, or promises "guaranteed" returns is a liability, not an asset.

Autonomous Agent

A single LangGraph ReAct agent orchestrates five tools without hard-coded steps, looping until it has gathered enough evidence to answer.

Private Knowledge - RAG

Answers are grounded in five company analyst reports through an in-memory ChromaDB index, and every claim is attributed to its source.

Dual Guardrails

Two independent methods - a fast rule-based check plus an LLM judge - guard both the input and the output. Every decision is written to an audit log.

Component Reference

The Four Layers

LayerRole
Tool infrastructure
FastMCP server		Exposes five tools over the Model Context Protocol so the agent never calls external APIs directly.
Reasoning engine
LangGraph		A single ReAct-style agent that decides which tool to call and loops until the answer is complete.
Private knowledge
ChromaDB + RAG		Grounds answers in proprietary analyst reports using text-embedding-3-small, with citations.
Safety layer
Dual guardrails		Blocks injections at the input; softens over-confidence and prevents leakage at the output.
