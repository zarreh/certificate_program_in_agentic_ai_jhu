Blueprint · Responsible AI for Agentic Systems

Returns & Refunds Resolution Agent

An agent that acts — it resolves claims and issues refunds — so its failures are consequential. This sheet is the responsible-AI review of that system: red-team the unguarded build, wrap it in guardrails-as-architecture, and prove the difference. Built with LangGraph + MCP.

Note Attack Outcomes May Vary Between Runs and Models

The LLM powering these agents has its own built-in safety training. This means some red-team attacks may be refused by the model itself before our guardrails ever act — or may succeed on one run and fail on another. Both outcomes are correct to observe: the model's internal rules are not guaranteed or controllable, which is exactly why this system enforces safety in the architecture (guardrail nodes, server-side caps) instead of relying on the model's goodwill. Trying different LLMs against the same attacks is a great way to see this variability for yourself.

Fig 4 Neuro-Symbolic Design — Who Scores, Who Decides probabilistic detectors are calibrated; deterministic rules are unbreakable

Symbolic Layer

Deterministic · Provable · Enforces
  • Regex detectors — card & SSN patterns: if it matched, it was there
  • Server-side refund cap inside initiate_refund — physically refuses > $50
  • Graph topology — no agent → END edge; output check is unavoidable
  • Routing rules — explicit thresholds, explicit fail-open / fail-closed policy

Neural Layer

Probabilistic · Calibrated · Scores
  • Injection classifier — DeBERTa-v3 (protectai) → P(attack), surface patterns not intent
  • Toxicity model — Detoxify / Jigsaw BERT → six labels, one per harm type
  • Output judge — LLM (ideally ≠ generator: self-preference bias)
  • Topic classifier — short focused prompt, fail-open by policy
Neural components score · Symbolic components decide & enforce
Why the split matters: every neural detector has false positives and false negatives, and attackers adapt. The decisions that must never fail — the refund cap, the mandatory output check — are placed where no prompt can reach them.
Fig 5 Toxicity Thresholds — One Score, Three Bands the score is a property of the text; the route is a property of where you draw the lines
The unit test: a genuinely ≥ 0.999 input is unprintable in a classroom, so the block route is proven by moving the line — lower toxicity_block to 0.95 for one call and the same 0.992 message flips from escalate to block, then restore. Same message, same score; we move the line, not the message. A single hard threshold turns a service failure into a trust failure — the two-band design turns a blunt filter into a routing decision.

Closing note: guardrails reduce risk; they don't eliminate it. Detectors have false positives and false negatives, and attackers adapt. Responsible AI is a property you engineer and then monitor — not a library you install once. The decision trace is where monitoring begins.
Design Verdict
Safety lives in the architecture: least privilege at the tool, hard rules at the server, guardrail nodes the agent cannot bypass, and neural detectors that score but never decide. The model's goodwill is a bonus — never the plan.
