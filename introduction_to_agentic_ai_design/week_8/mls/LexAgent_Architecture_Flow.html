FIG. 3

The ReAct loop, made explicit

One lap = one reasoning turn. The loop repeats until the model writes a Final Answer — or hits the 8-step cap.

Four guardrails keep it honest

Stop sequence on "Observation:"

The model is physically cut off before it can invent an observation. Evidence comes only from the server.

Schemas in the prompt

Each tool's argument schema + a worked Action Input example, so the model sends plain values — not the schema echoed back.

Full scratchpad replay

Every prior Thought / Action / Observation is fed back each turn — later steps (clause rewriting) reuse earlier evidence.

Visible failure handling

Malformed turns become an explicit system note — never disguised as a tool observation. The agent gets a bounded retry within the MAX_AGENT_STEPS = 8 cap.

FIG. 4

Five tools, one server

All registered with @mcp.tool() on FastMCP. Mixed mechanics: rules, RAG, live web, and a nested LLM.

TOOL 01 parse_query

Gatekeeper. Validates the question is housing-law, tags intent, tenancy & issues. Rejects out-of-scope.

■ rule-based · deterministic
TOOL 02 policy_search_tool

Semantic search over the tenant-rights statute KB. Returns top-2 policy excerpts.

■ RAG · Chroma k=2
TOOL 03 cases_search_tool

Semantic search over prior NY housing-court cases (pre-2023). Returns top-3 precedents.

■ RAG · Chroma k=3
TOOL 04 tavily_web_search_tool

Live web search for law from 2023 onward — the fallback when the local KB has a gap.

■ web · Tavily API
TOOL 05 rewrite_legal_clause

Rewrites lease clauses for compliance — grounded in the evidence retrieved by tools 1–3.

■ LLM · evidence-grounded

FIG. 6

Two judges, one verdict

Deterministic checks

  • tool sequence right tools, right order — parse first
  • scope handling confirmed in-scope / rejected out-of-scope
  • answer content required rulings & steps present
  • no hallucination no statutes beyond retrieved context

LLM-as-a-Judge

  • groundedness claims traceable to retrieved evidence
  • faithfulness evidence quoted without distortion
  • answer relevance the user's actual question answered
  • citation precision statute references match the excerpts
