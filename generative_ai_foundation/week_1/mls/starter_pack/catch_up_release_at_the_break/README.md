# Do not open until your mentor says so

This folder exists so that nobody is left behind in the second half of the session.

`clinic_tracker_starter.py` contains:

- **`check_entry`, finished.** This is the piece built together in the first half. If your own
  version worked, you do not need this. If you fell behind, this puts you back on the same
  footing as everyone else.
- **`add_appointment`, named but not built.** This one is yours. That is the exercise.

Opening this early means watching the first half instead of doing it, which is the one thing
that will stop the session working for you.
