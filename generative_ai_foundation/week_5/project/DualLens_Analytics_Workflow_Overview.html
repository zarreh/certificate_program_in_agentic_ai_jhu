Project Overview

DualLens Analytics is an investment research system built to fix what a failed pilot got wrong: it generated answers and stopped, with no metadata filtering, no measurement, and no way to know when to trust its own output. Every generation stage here is paired with a measurement stage, and those measurements feed back into improving the system - culminating in a ranked recommendation that carries an honest, evidence-based confidence score.

The Problem

A confident-sounding pilot nearly shipped a hallucinated answer and mixed up companies during retrieval. Numbers alone don't justify a valuation - the AI-strategy evidence has to be verified too, and the system has to know how sure it is.

Dual-Lens Fusion

A quantitative financial lens (yfinance metrics) and a qualitative narrative lens (company-tagged RAG over analyst PDFs) are combined so every investment rank cites a metric and a named initiative.

Judge-Driven Evaluation

Three LLM-as-Judge rubrics - Groundedness, Context Relevance, Answer Relevance - are cross-validated against a 20-question objective gold set, so subjective scoring is never the only signal.

Self-Improving Prompts

DSPy + GEPA rewrites the RAG prompt using measured failure feedback from the gold set - trained on 12 questions, proven on 8 the optimizer never saw.

Component Reference · Pipeline & Cast

The Six Steps

StepLayerWhat Happens
1
Financial Lens		Datayfinance 3-year price history + 5 metrics (Market Cap, P/E, Dividend Yield, Beta, Revenue) for 5 companies.
2
Narrative Lens		Data5 analyst PDFs split into 512-token chunks (64 overlap), each tagged with a company metadata field, embedded into ChromaDB.
3
Grounded RAG Q&A		ReasoningCompany-filtered retrieval (top_k=4) plus a strict "answer only from context, else say I don't know" prompt (v1.0).
4
Judge Harness		Evaluation3 LLM-as-Judge rubrics (1-5 each) plus a 20-question objective gold-set accuracy check - two independent measurements.
5
GEPA Optimization		OptimizationDSPy + GEPA evolves the prompt using failure feedback from 12 training questions; proven on 8 held-out questions (v1.0 → v2.0).
6
Fused Ranking		DecisionFinancial metrics + retrieved AI-initiative evidence are ranked together, scored for confidence, and routed.
