🏦 Senior Mortgage Underwriting System

Multi-Agent Underwriting with MCP Tools, A2A Critic Service, RAG Policy Grounding, Human-in-the-Loop and DeepEval
LangGraph • MCP • A2A • RAG • DeepEval • gpt-4o-mini

System Overview

A loan file is sanitized before the workflow ever sees it. Four specialist agents (credit, income, asset and collateral) analyse the file, each reading only its own policy area and calling deterministic calculators served over MCP. An LLM Supervisor plans the work and drives a bounded rework loop, while the Critic, the one agent exposed as an A2A service, peer-reviews the analyses. A Decision Agent issues a risk-scored verdict, and only a conditional approval pauses for a senior underwriter. Every run is scored with six DeepEval agentic metrics.

Specialized Agents

Four analysts, each owning one policy area (credit 1.x, income 2.x, asset 3.x, collateral 4.x). All four are bound the full MCP tool set and choose their own tools with bind_tools.

Coordination Layer

An LLM Supervisor emits an ordered plan, routes work and enforces MAX_REVISIONS = 3. The Critic returns a pass/fail verdict over A2A. The Decision Agent synthesises the verdict.

Compliance & Security

PII is redacted before the graph is invoked, so raw identifiers never reach state or the checkpointer. Every agent output is screened for protected-characteristic language, and policy retrieval cites section numbers.

Human-in-the-Loop

Only a CONDITIONAL_APPROVAL pauses via LangGraph interrupt(). The senior underwriter resumes the case with Command(resume=...), and any override must carry a justification.
